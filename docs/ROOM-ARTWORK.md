# Room illustrations

Created using the built-in image generation tool. These are conceptual illustrations, not photographs of the property. Each thumbnail is captioned with its specific room name in English and Bengali. Unknown names retain the supplied room name; room codes are never used to guess a name. All six final files are saved in `public/images/room-illustrations/` in the Laravel workspace and `assets/rooms/` in the Flutter app.

The artwork is selected using the actual supplied room name, room type, AC type and bed type. The waiting-room name and suite type take precedence; the remaining rooms use the AC/non-AC and bed-type fields. An image is not evidence of a room’s actual amenities or view.
